# Contributing

Thank you for your interest in the Azure Cloud Portfolio.

This is a personal portfolio project focused on documenting my learning journey in Microsoft Azure, including certifications, hands-on laboratories, technical documentation, and cloud projects.

Contributions are not accepted without prior agreement from the project author.

## Reporting Issues

Bug reports, documentation corrections, and improvement suggestions are welcome.

Please open an issue in the [GitHub repository](https://github.com/JordiMiravet/azure-cloud-portfolio/issues).

When reporting an issue, provide a clear description of the problem or suggestion and include reproduction steps when applicable.
